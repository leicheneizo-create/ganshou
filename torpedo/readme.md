# ディープシー・レティクル：数学攻勢 (Deep Sea Reticle: Math Offensive)

潜水艦の魚雷発射を制御し、一次関数と連立方程式の知識を駆使して敵艦を撃破する学習型シミュレーションゲームです。

## 概要
中学1年生（中1）の数学で学習する「一次関数」および「二元一次方程式・連立方程式」の概念を、直感的かつ実戦的な形式で学ぶことができます。

## ターゲット
*   一次関数の「傾き (k)」と「切片 (b)」の視覚的な意味を理解したい学生
*   連立方程式の解が「2つの直線の交点」であることを体験したい学生
*   数学を実際のシミュレーション（火器管制システム）として応用してみたい方

## 遊び方
1.  **火器管制システムへの入力**:
    *   `k` (傾き): 魚雷が1進むごとにどれだけ深さが変わるかを設定します。
    *   `b` (切片): 潜水艦の初期深度を設定します。
2.  **レベル1 (静止目標)**:
    *   画面上の赤いターゲットを狙います。
    *   `(目標のy - 自分のb) / 目標のx` を計算して `k` を求めましょう。
3.  **レベル2 (動的目標 - 連立方程式)**:
    *   敵艦が一定の方程式に沿って移動しています。
    *   自分の魚雷の軌道と敵艦の軌道の交点（連立方程式の解）を予測して撃ち込みます。

## 教育的特徴
*   **リアルタイム・プレビュー**: 数値を入力すると、魚雷の予定軌道がレーダー上に点線で表示されます。これにより、パラメータの変化がグラフにどう影響するか即座に理解できます。
*   **タクティカル UI**: ガラスモーフィズムを用いた暗紺色のレーダー画面により、没入感のある学習体験を提供します。
