# ディープシー・レティクル：数学攻勢 (Deep Sea Reticle: Math Offensive)

潜水艦の魚雷発射を制御し、一次関数と連立方程式の知識を駆使して敵艦を撃破する学習型数学シミュレーションゲームです。

## 概要
中学・高校数学で学習する「一次関数」および「連立方程式」、そして「速度ベクトル」の概念を、直感的かつ実戦的な形式で学ぶことができます。

## ターゲット
*   一次関数の「傾き (k)」と「切片 (b)」の視覚的な意味を理解したい学生
*   連立方程式の解が「2つの直線の交点」であることを体験したい学生
*   「速さ」と「進む方向（成分）」の関係を物理的に理解したい方

## ミッション構成（全5ステージ）
1.  **MISSION 01: 直線移動（静止目標）**
    *   傾き k を調整して、固定ターゲットを撃破。(x, y) の比例関係を学びます。
2.  **MISSION 02: 速度の効果（動的目標）**
    *   逃走するターゲットを高速魚雷で追跡します。魚雷のスピードが上がると、いかに「撃破地点が手前（短距離・短時間）になるか」を体験します。
3.  **MISSION 03: 方程式の交点（連立方程式）**
    *   敵艦が一定の方程式 y = ax + c に沿って移動。自分の魚雷軌道との交点（連立方程式の解）を予測して撃ち込みます。
4.  **MISSION 04: 比例の追撃（ベクトル追従）**
    *   初期深度 b = 0 からの追撃。目標時間内に指定座標を通過するための適切な k を算出します。
5.  **MISSION 05: 斜率と速度の関係（高度な物理）**
    *   魚雷の「総速度」が一定であるという物理的制約。傾き k を大きくすると水平速度 Vx が落ちる現象 (Vx = Vtotal / sqrt(1 + k^2)) を学び、最適な迎撃タイミングを導き出します。

## 基本概念と詳細解説 (Basic Concepts & Detailed Explanation)

このゲームを通じて学習できる数学・物理の核心的な概念を以下に解説します。

### 1. 一次関数の基本： y = kx + b
*   **傾き (k) [Slope]:** 魚雷が進む「坂道の険しさ」を表します。
    *   k = 0: 真横（水平）に進みます。
    *   k = 1: 45度の角度で進みます。
    *   k = 2: さらに急な角度で進みます。
*   **切片 (b) [Intercept]:** 魚雷が発射される「初期深度（y座標）」を表します。
    *   潜水艦の垂直位置を調整して、発射ラインを決める役割を持ちます。

### 2. 連立方程式と交点 (Simultaneous Equations)
ミッション03などでは、敵艦も直線 y = ax + c に沿って動きます。
*   魚雷を命中させるには、**「魚雷の軌道」と「敵の軌道」が重なる点（交点）**を計算する必要があります。
*   数学的には、2つの方程式 y = kx + b と y = ax + c を同時に満たす (x, y) を求める「連立方程式」を解く作業と同じです。

### 3. 【高度】傾きと速度のトレードオフ
ミッション05で登場する、最も重要な物理的・数学的な関係です。
*   **全速力は一定:** 魚雷のエンジンが出せる「パワー（総速度 Vt）」には限界があります。
*   **速度の配分:** 
    *   「傾き k」を大きくして急な坂道を登ろうとすると、その分「前に進む速度 Vx」が犠牲になります。
    *   反対に、水平（k = 0）に進めば、すべてのパワーが「前進」に使われるため、ターゲットに最短時間で到達します。
*   **戦略:** 遠くの敵を迎え撃つには、むやみに傾斜をつけるのではなく、敵の移動速度を計算して「最も効率的な角度」を見つけ出す必要があります。

### 【深掘り】傾き (k) の持つ意義

このゲームにおける「傾き k」は、数学と物理の両面において重要な意義を持っています。

#### ● 数学的意義：変化の割合 (Rate of Change)
数学の世界では、傾き k は **「 x が 1 増えたときに、y がどれだけ増えるか」** という変化の割合 (dy / dx) を示します。
*   k > 0: x が増えるにつれて y も増える（右肩上がり）。
*   k < 0: x が増えるにつれて y が減る（右肩下がり）。
*   k = 0: y は常に一定（垂直ではない水平移動）。

#### ● 物理的意義：方向のベクトル (Orientation)
物理の世界では、この「変化の割合」は **「速度の配分」** を意味します。
*   魚雷が斜めに進むとき、その進行方向は「水平速度 (Vx)」と「垂直速度 (Vy)」の比率によって決まります。
*   このとき、**k = Vy / Vx** という関係が成り立ちます。
*   つまり、数学の「直線の傾き」を調整することは、物理的には「魚雷の舵を切り、縦と横の速度をどう分配するか」を管理することと同義です。

#### ● 現実世界の例
*   **道路の勾配:** 山道の標識にあるパーセント表示（例：10%）は、この傾き k を百分率にしたものです。
*   **階段の設計:** 階段の一段の「高さ」と「踏み面」の比率が k になり、昇りやすさを決定します。
*   **航空機の離陸:** 旅客機が離陸する際の角度も、水平方向への加速と上昇率のバランスである k によって管理されています。

## 教育的特徴
*   **リアルタイム・シミュレータ**: パラメータ $(k, b)$ を入力すると、速度成分 ($V_x, V_y$) や到達予想時間が即座に計算・表示されます。これにより数式と物理量の関係を即座にフィードバック。
*   **タクティカル UI**: ダークモードとガラスモーフィズムを採用したレーダー画面により、数学が「システムの制御」にどう使われているかという実用的な側面を演出。
*   **フィジカル・フィードバック**: 斜率の変化に応じて魚雷の実際の進行スピード（水平・垂直成分）が変化するため、グラフ上の傾きが「速さの配分」であることを直感的に理解できます。
